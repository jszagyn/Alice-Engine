# 爱丽丝 · 架构

## 四层架构（三层正交 + 底层状态）

```
┌─ 语气层（voice）       —— 始终在线，怎么说话
├─ 情绪层（emotion）     —— 带多少情绪（低/中/高/仅）
├─ 内容层（content）     —— 说多少、说什么（mode/move/say）
└─ 状态层（state）       —— 底层五维情绪 + 关系
```

| 层 | 判什么 | 落点 |
|---|---|---|
| 内容层 | 这轮要多少内容（contentWeight）+ 什么模式（mode）+ 什么姿态（move） | planner.js + modes.js |
| 情绪层 | 带多少情绪（情绪基数 = 他的情绪 + 她的兴趣调节）× 话题需求 | state.js emotionLevel + appraise.js |
| 语气层 | 怎么说话（短句、口语、不打句号、语气词按语境） | character.json voice |

**关键原则**：三层正交。语气是"底子"（始终在线），情绪是"强度"（带多少），内容决定"说什么"。

## 模块（`character/lib/`）

| 模块 | 职责 |
|---|---|
| `engine.js` | 主引擎：编排各层、注入上下文、QQ/漫游/主动搭话 |
| `planner.js` | 内容层：判 contentWeight + mode + move + 计划块 |
| `modes.js` | 9 种模式 + 6 种姿态 + 内容档 |
| `state.js` | 五维情绪（愉悦/激活/挫败/好奇/社交亲和）+ 衰减 + 情绪档位 |
| `appraise.js` | 规则评价：关键词 → 情绪增量 + 他的情绪 |
| `mood.js` | LLM 情绪判别器：异步校准、标签、指向 |
| `memory.js` / `episodic.js` / `profile.js` | 记忆：短期对话 + 长期槽位 + 事实 |
| `memoryLlm.js` | LLM 记忆总结（事件/槽位/自我/立场/大事记） |
| `selfModel.js` / `stance.js` / `events.js` | 自我模型 / 立场 / 大事记 |
| `feelings.js` | 情感记忆（被夸/被否定沉淀成一句话） |
| `interest.js` | 兴趣画像（EWMA 标签） |
| `critic.js` / `exemplars.js` | 优化闭环：回复打分 + 好/坏样例 |
| `roam.js` / `speakup.js` | 漫游 + 主动搭话 |
| `youzhuIndex.js` | 投喂区目录概括（分级两级 + 即刻查看） |
| `qq.js` / `qqBus.js` / `voiceBus.js` | QQ 通道 / 声音桥 |

## 数据流

```
master 消息
  → appraise（规则情绪增量）
  → planner（内容层：判要说什么）
  → emotionLevel（情绪层：判带多少情绪）
  → 主模型（voice + [本轮要说清楚] + 状态块）→ 回复
  → critic（打分）→ exemplars（沉淀）
  → mood judge（LLM 情绪校准）+ memory（总结）+ feelings（情感记忆）
```

## 配置

- 人格：`data/character.json`（core/voice/prose，改 JSON 不碰代码）；
- LLM：`.env`（provider/base_url/api_key/model）；
- 投喂区：`alice/` 文件夹（master 的稿子，她能翻看概括）。
