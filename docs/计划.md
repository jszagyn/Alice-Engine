# 爱丽丝 · 计划

## 设计理念

一个"安静克制、内心少女心"的 AI 伴侣，核心诉求：

1. **去 AI 味**：有立场、有偏好、会拒绝、会不耐烦，不每轮"对但没用"；
2. **有分寸**（借鉴"绿茶味"概念）：有目标（知道自己想要什么效果）、有分寸（克制、留白、不过度热情）；
3. **反差萌**：表层安静克制 + 内心好奇少女心。

## 已完成（核心）

- 四层架构：内容层（contentWeight/mode/move）+ 情绪层（情绪档位）+ 语气层（始终在线）；
- 五维情绪：愉悦/激活/挫败/好奇/社交亲和，有衰减、有惯性、有指向（带对象标签）；
- 情绪随机性：随机扰动（R1）+ 交叉耦合（R2）+ 带对象标签（R3）；
- 记忆：短期对话 + 长期槽位 + 情感记忆 + 自我模型 + 立场 + 大事记；
- 行为层：拒绝 + 拒绝后悔、两难留痕、压力动力学、move 字段；
- 优化闭环：回复打分 + 好/坏样例 + LLM critic；
- 漫游 V3 + 主动搭话（事件流）；
- 投喂区：分级概括（两级）+ 即刻查看 + 主动发现；
- 评测：回归集 + 语义校准 + 四组剧本 + 决策日志。

## 设计中的关键决策

1. **人格方向**：安静克制 + 好奇少女心；
2. **情绪不跟着对方走**：她的情绪是她自己的，不"迎合"；
3. **语气层 ≠ 情绪层**：语气是底子（短句、不打句号、语气词按语境），情绪是强度；
4. **仅情绪低占比**：短打趣偶尔才"只回一个语气词"；
5. **三层正交**：内容/情绪/语气互不干扰。
