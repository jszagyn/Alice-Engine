# 自定义你的 AI（零编程，改两个文件就行）

想把她换成你喜欢的样子？改下面两个文件，**改完重启**就生效。

## 两个文件在哪

| 文件 | 管什么 |
|---|---|
| `persona\人格.md` | **她是谁**：性格、底线、在意什么、怎么称呼你 |
| `persona\语气.md` | **她怎么说话**：短句、语气词、句号、停顿 |

用记事本（或任何文本编辑器）打开就能改，**不用懂代码、不用懂 JSON**。

---

## 改法示例

### 1. 改名字

打开 `persona\人格.md`，第一行：

```
你是爱丽丝。你按人的方式想事情……
```

把「爱丽丝」换成你想要的：

```
你是小明。你按人的方式想事情……
```

### 2. 改性格

`人格.md` 里有一句「你的性格底色是「安静克制」，不是活泼」。

- 想要**活泼话多**：
  ```
  你的性格底色是「活泼外向」，爱开玩笑、话多、有活力。
  ```
- 想要**温柔体贴**：
  ```
  你的性格底色是「温柔体贴」，说话软、会照顾人情绪。
  ```
- 想要**高冷毒舌**：
  ```
  你的性格底色是「高冷毒舌」，话少但一针见血，爱怼人。
  ```

### 3. 改说话方式（语气）

打开 `persona\语气.md`。

- 想**句末加句号**：删掉「句末不加句号」这一行；
- 想**爱用感叹号**：把那行改成「句末爱加感叹号，情绪外放一点」；
- 想**多话**：把「一轮一到两句就收」改成「一轮可以多说几句」。

### 4. 改称呼

`人格.md` 里找「你叫对方」这一句：

```
你叫对方 master，平时也说「你」。
```

改成：

```
你叫对方主人，平时也说「你」。
```
或
```
你叫对方宝贝。
```
或
```
你叫对方哥们。
```

### 5. 加口头禅

`语气.md` 里随便加一句：

```
你偶尔会说「啧，真行」。
```

---

## 改完怎么办

1. 保存文件；
2. 双击桌面的「停止」再「启动」（重启一下）；
3. 跟她聊天，人设就换了。

## 改错了想还原

把 `persona\人格.md` 或 `persona\语气.md` **删掉**，重启后就会回到默认人设（默认值存在 `character\data\character.json` 里）。

---

**一句话**：改「人格.md」换性格，改「语气.md」换说话方式，改完重启。就这么简单。
